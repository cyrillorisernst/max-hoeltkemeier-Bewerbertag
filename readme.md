Installationsanweisung:
Geschrieben wurde dieses Tool für live Server extensions, da es typeScript nutzt aber in HTML abgebildet wird. Das hat den Grund dass keine großen Installationen von z.B: Node stattfinden müssen, um TypeScript vorher zu JavaScript zu compilen, sondern dieser Schritt extern, per importiertem Script, übeernommen wird. Besagte HTML Seite lässt sich mit z.B.: Einer VS-Code Extension (Live Server) in wenigen Klicks abbilden.

1. Das Programm soll als ausführbares Command Line Tool funktionieren. Sollte noch Zeit übrig sein, ist Error handling einzubauen. Danach ist ein Webinterface aufzusetzen eine Option. Sollte anschließend noch mehr Zeit sein, ist über Persistence der Daten nachzudenken.

2. Die Funktionen des Programms sollen so entwickelt werden, dass sie unabhängig des User Interfaces nutzbar bleiben.

3. womöglich war es genau verkehrt herum, geraete Mitarbeitern oder Container zuzuordnen und der Ausleihzustand des Geräts sollte im Gerät selbst verortet sein.

4. Es wäre von Vorteil gewesen eine feste Liste einer Vorauswahl an Gerätetypen einzubinden (Datenpflege)
